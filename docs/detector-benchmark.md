# Detector benchmark

Generated by `python -m benchmark.run --days 5 --seeds 7,11,23` (3 independent 5-day runs pooled per row). Synthetic traffic with the simulator's daily pattern (nightly batch 02:00–03:30 at 8% errors, morning peak 09:00–11:00 at 4%), 2% background errors, 4 benign 20 s blips/day and 6 injected incidents/day (spike 35%/2 min, moderate 12%/4 min, ramp 2→25%/10 min). Scored on the last 2 days of each run. Same detector code as the live service.

False alarms/day are split into **pattern** (the expected nightly batch / morning peak hours), **blip** (short self-healing bursts) and **noise**.
